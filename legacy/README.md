# Historical predecessors / 历史前身

`v1-v2/` contains shell helpers and the Flask v2 starter plus incremental patches. `early-v3/` contains recovered pre-Git Electron development snapshots. These are archival sources, not dependencies of the current application. Personal config, media, generated packages, caches and virtual environments are excluded. Historical paths were anonymized and may require adaptation; use the root README for the supported current workflow. No independent valid Git history was present in these predecessor folders.
