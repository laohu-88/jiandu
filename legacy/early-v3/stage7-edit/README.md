# 视频剪辑编排器 v3

当前版本：`v3.0.0-stage7`

## 工具定位

视频剪辑编排器 v3 是一个真正的 Electron 桌面 App，用来给“分段口播视频”做剪辑前置编排。它负责从素材整理、视频方案导入、配音匹配、分段素材编排，一直走到分段粗剪、总粗剪、FCP 交接清单和整片字幕收口。

它不是浏览器控制台，也不依赖 Flask、Chrome 或 `127.0.0.1` 本地服务。项目文件都保存在用户选择的项目目录中，不写入 App 包内部。

## 启动开发版

```bash
npm install
npm start
```

## 打包 Mac App

```bash
npm run build:mac
```

当前打包目标是 Apple Silicon Mac 的 `.app` 目录包，不要求签名、不要求 notarize、不生成 dmg。默认产物位于：

```text
dist/mac-arm64/视频剪辑编排器 v3.app
```

## 标准使用流程

1. 创建项目。
2. 把素材放入 `01-精选素材`。
3. 在 App 中扫描素材。
4. 生成素材简报。
5. 把素材简报发给 GPT，生成分段视频方案。
6. 导入视频方案。
7. 把分段配音放入 `02-配音`。
8. 扫描配音并读取时长。
9. 给每段编排素材。
10. 自动补齐素材时长到配音时长。
11. 同步分段素材包到 `03-分段素材包`。
12. 生成分段粗剪到 `04-分段粗剪`。
13. 生成总粗剪到 `05-总粗剪/full-roughcut.mp4`。
14. 进入 Final Cut Pro 精剪。
15. 从 FCP 导出整片到 `06-FCP导出`。
16. 在 App 中生成或整理整片字幕，输出到 `07-字幕`。

## 文件夹说明

创建项目后会生成：

```text
项目名/
├─ 00-项目总控/
├─ 01-精选素材/
├─ 02-配音/
├─ 03-分段素材包/
├─ 04-分段粗剪/
├─ 05-总粗剪/
├─ 06-FCP导出/
└─ 07-字幕/
```

关键文件：

- `00-项目总控/project.json`：项目状态。
- `00-项目总控/assets.json`：精选素材索引。
- `00-项目总控/素材简报.md`：给 GPT 的素材简报。
- `00-项目总控/video-plan.md`：导入的原始视频方案。
- `00-项目总控/segments.json`：分段结构和配音信息。
- `00-项目总控/segment-assignments.json`：每段素材编排。
- `00-项目总控/roughcut-status.json`：分段粗剪状态。
- `00-项目总控/final-roughcut-status.json`：总粗剪状态。
- `00-项目总控/FCP交接清单.md`：FCP 精剪交接清单。
- `00-项目总控/subtitle-status.json`：整片字幕状态。
- `07-字幕/final-cn.srt`：整理后的中文字幕。

## ffmpeg / ffprobe 依赖说明

App 会直接调用本机的 `ffmpeg` 和 `ffprobe`：

- `ffprobe` 用于读取图片、视频、音频时长和尺寸。
- `ffmpeg` 用于生成分段粗剪、合并总粗剪。

如果检测不到 `ffmpeg` 或 `ffprobe`，App 不会崩溃，但相关功能会提示不可用。可以在 App 的“检测运行环境”区域查看当前状态。

macOS 上常见安装方式：

```bash
brew install ffmpeg
```

## ww 字幕命令说明

Stage 6/7 支持可配置字幕命令，默认是：

```text
ww
```

配置文件保存在：

```text
00-项目总控/subtitle-config.json
```

如果 `ww` 只是 iTerm2/zsh 里的 alias，Electron 可能无法直接识别。此时可以在 App 里填写真实命令路径或脚本路径；也可以手动生成 `raw.srt`，放入 `07-字幕/raw.srt`，再点击“整理已有 SRT”。

## 当前已实现范围

- 创建、打开项目
- 最近项目列表
- 运行环境检测
- 检查并补齐项目目录
- 扫描 `01-精选素材`
- 自动分配 `A001` 格式编号
- 读取图片和视频基础信息
- 保存 `assets.json` 与 `project.json`
- 生成 `素材简报.md`
- 导入并解析视频方案
- 保存 `video-plan.md` 与 `segments.json`
- 扫描 `02-配音`，按数字前缀匹配分段
- 使用 ffprobe 读取配音时长
- 为每个分段编排素材、时长、显示方式和原声策略
- 自动对齐素材总时长与配音时长
- 同步完整原素材、配音和分段计划到 `03-分段素材包`
- 使用 ffmpeg 生成 1920×1080、30fps 的 H.264/AAC 分段粗剪
- 保存粗剪状态与失败日志
- 合并所有分段粗剪到 `05-总粗剪/full-roughcut.mp4`
- 生成 `00-项目总控/FCP交接清单.md`
- 对 FCP 导出的整片视频生成/整理字幕
- 将字幕统一收纳到 `07-字幕`
- 生成 `final-cn.srt`、`final-cn.txt` 与 `subtitle-report.md`
- 打包为 macOS `.app`
