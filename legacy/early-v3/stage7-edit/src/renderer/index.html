开始一个视频项目

创建新项目，或打开已有项目文件夹。所有项目文件都会保存在你选择的项目目录中。

  1. 创建项目后，把素材放进 01-精选素材。
  2. 扫描素材并生成素材简报。
  3. 拿素材简报给 GPT 生成视频方案。
  4. 导入方案、配音、编排素材并生成粗剪。
