# Public-source preparation

The public history retains the local project's commit sequence and code evolution, while replacing personal home-directory paths and private commit identities. Commit hashes necessarily change. Historical references to absent sample footage are illustrative, not supplied footage. Current tracked media fixtures are tiny synthetic placeholders, not personal video.

Private untracked analysis files, source footage, runtime state, local handoffs, packaged applications, caches, credentials and install backups are excluded. The installed Skill was older than the source Skill; the source Skill is the published version.

Credential-pattern scans and a path/email review are performed on reachable Git objects before publication. This is a bounded audit, not a guarantee that arbitrary secrets are mathematically detectable. Do not add real credentials or personal media in future contributions.
